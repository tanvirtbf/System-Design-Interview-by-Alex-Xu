# Single Server Setup (Chapter 1)

> Note: বইয়ের original figure গুলো আমার কাছে ছিল না, তাই নিচের diagram গুলো বইয়ের text অনুযায়ী আমি নিজে এঁকেছি।

## মূল idea

শুরুতে user কম থাকে, তাই সবকিছু **একটাই server এ** চালানো হয়:
web app, database, cache, সব এক জায়গায়।

### Figure 1-1: Single server setup

```
                 +--------------------------------+
                 |          ONE SERVER            |
   Users  -----> |  +----------+  +------------+  |
 (Web/Mobile)    |  | Web App  |  |  Database  |  |
                 |  +----------+  +------------+  |
                 |  +----------+                  |
                 |  |  Cache   |                  |
                 |  +----------+                  |
                 +--------------------------------+
```

## Request flow (Figure 1-2)

User যখন `api.mysite.com` এ যায়, তখন এই ৪টা step হয়:

```
  User (Browser / Mobile App)
      |
      | (1) api.mysite.com এর IP কী?
      v
  +---------+
  |   DNS   |   <-- third-party paid service, আমাদের server এ থাকে না
  +---------+
      |
      | (2) IP address ফেরত দেয়: 15.125.23.214
      v
  User (Browser / Mobile App)
      |
      | (3) HTTP request পাঠায় ওই IP তে
      v
  +-------------+
  | Web Server  |   (IP: 15.125.23.214)
  +-------------+
      |
      | (4) HTML page বা JSON response ফেরত দেয়
      v
  User (rendering করে)
```

### Step by step

1. **Domain name দিয়ে access:** User `api.mysite.com` এর মতো domain ব্যবহার করে। Domain Name System (DNS) সাধারণত third-party দের paid service, আমাদের নিজের server এ host করা হয় না।
2. **IP address return:** DNS ওই domain এর IP address browser বা mobile app কে ফেরত দেয়। উদাহরণে `15.125.23.214`।
3. **HTTP request:** IP পাওয়ার পর HTTP (Hypertext Transfer Protocol) request সরাসরি web server এ পাঠানো হয়।
4. **Response:** Web server rendering এর জন্য **HTML page** অথবা **JSON** ফেরত দেয়।

## Traffic কোথা থেকে আসে?

Web server এ traffic আসে দুই source থেকে:

```
  +------------------+        +------------------+
  | Web Application  |        | Mobile App       |
  +------------------+        +------------------+
           \                         /
            \                       /
             v                     v
            +-----------------------+
            |      Web Server       |
            +-----------------------+
```

### 1. Web application
- **Server-side language** (Java, Python ইত্যাদি): business logic আর storage handle করে।
- **Client-side language** (HTML ও JavaScript): user কে page দেখানোর (presentation) কাজ করে।

### 2. Mobile application
- Mobile app আর web server এর মধ্যে communication protocol হলো **HTTP**।
- Data transfer এর জন্য সাধারণত **JSON** (JavaScript Object Notation) ব্যবহার হয়, কারণ এটা simple।

### API এর উদাহরণ

```
GET /users/12      -->  id = 12 এর user object ফেরত দাও
```

Response (বোঝার জন্য একটা illustrative JSON, বইয়ের exact নয়):

```json
{
  "id": 12,
  "firstName": "John",
  "lastName": "Smith"
}
```

## মনে রাখার পয়েন্ট

| বিষয় | সারকথা |
|---|---|
| Setup | সবকিছু (web app, DB, cache) এক server এ |
| DNS | Domain কে IP address এ convert করে, third-party service |
| Protocol | Client থেকে server এ HTTP |
| Response format | HTML (web) বা JSON (mobile/API) |
| Traffic source | Web app + Mobile app |

## সীমাবদ্ধতা (কেন এটা যথেষ্ট না)

User বাড়লে একটা server এ সব রাখা যায় না। একই machine এর CPU আর memory web আর database ভাগ করে নেয়, আর server বন্ধ হলে পুরো system বন্ধ। এই কারণেই পরের topic এ web tier আর database আলাদা করা হয়।
